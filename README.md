# CyanSalt's Agent Skills

[![AI-DECLARATION: auto](https://img.shields.io/badge/AI--DECLARATION-auto-ede9fe?labelColor=ede9fe)](https://ai-declaration.md)

## Installation

Install all Skills from this repository:

```shell
pnpm dlx skills add CyanSalt/skills
```

Install a specific Skill:

```shell
pnpm dlx skills add CyanSalt/skills --skill <skill-name>
```

## Skills

| Skill | Description |
|-------|-------------|
| [design-as-me](skills/design-as-me/SKILL.md) | Designs and refines pages using my personal design preferences. |
| [design-as-them](skills/design-as-them/SKILL.md) | Creates a personalized `design-as-me` skill from the user's design preferences. |
